# Project Instructions & Agent Guidelines

## Design & Front-End Implementation
All UI/UX design, frontend components, and layout work in this repository MUST strictly comply with [DESIGN_PRINCIPLES.md](./DESIGN_PRINCIPLES.md).

Before touching any UI code:
1. Inspect existing tokens and components first.
2. Never hardcode colors, spacing, or sizing values.
3. Adhere to WCAG 2.2 AA accessibility standards.
4. Verify states (default, hover, focus, disabled, loading, empty, error).
5. Verify responsive layout at 360px, 768px, 1024px, 1440px.
6. Provide the final report matching Section 16 of [DESIGN_PRINCIPLES.md](./DESIGN_PRINCIPLES.md).
